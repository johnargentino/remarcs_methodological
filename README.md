This repository accompanies a methodological paper outlining the REMARCS algorithm, which is then tested on simulated data 
and a case study of household food security data collected by the World Food Programme.

The input folder contains anonymized survey data
The scripts folder contains the R markdown file that runs simulations, and which writes tables and commands directly into the 
output folder. The output folder contains a directory entitled "paper", which is a LaTeX project that will automatically update the 
paper with the output from the R script.

The docs folder contains an html file generated by the R Markdown file that is hosted on Github and allows for the ready to interact 
with a 3d graphic, the 2d version of which is in the paper.
