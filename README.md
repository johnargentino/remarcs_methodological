This repository accompanies a methodological paper outlining the REMARCS algorithm, which is then tested on simulated data 
and a case study of household food security data collected by the World Food Programme.


A pdf file of the paper itself is contained in the directory output -> paper -> main -> main.pdf. The folder entitled "paper" contains
a LaTeX Project that can was built in VS Code. 

The input folder will contain anonymized household food security survey data from Honduras. 

The scripts folder contains the R markdown file that loads necessary packages, runs simulations, and writes tables and commands directly into the 
LaTeX project, automatically updating the paper with R Markdown output. Seeds are set at the beginning of each chunk of code for replication purposes,
but seeds can be changed and results easily viewed in the updated pdf.

The docs folder contains an html file generated by the R Markdown file that allows the reader to interact 
with a 3d graphic displaying the bias introduces by adding noise to an AR(1) process and fitting said sum as though it were still AR(1).
This bias is juxtaposed against the superior estimation of the AR parameter that occurs if the resulting sum is treated instead as an ARMA(1,1) process.
This html file is linked to in the caption of the 2d version of the graphic, which is found in the paper.
