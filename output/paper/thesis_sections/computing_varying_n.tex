\subsection{Reducing Computing Time for Varying Daily Sample Sizes}

We now adapt the above section to accommodate varying $\{n_t\}$. First we define the $T\times T$ matrix $N$ so that $X_t'X_t = N,$ with $N = \text{Diag}(n_1,...,n_T)$. 

Next let $\mathbf{r}$ to be an eigenvector of $N^{1/2}\Gamma N^{1/2}$ with corresponding eigenvector $\lambda$. If $\mathbf{p}$ is then defined as $N^{-1/2}\mathbf{r}$, we can show that $X_t\mathbf{p}$ is then an eigenvector of $X_t\Gamma X_t$:


\begin{equation}
    \begin{array}{cc}
   X_t \Gamma X_t'(X_t\mathbf{p}) & \hspace{-.1in} = X_t \Gamma X_t'(X_tN^{-1/2}\mathbf{\mathbf{r}}) = X_t \Gamma NN^{-1/2}\mathbf{r} = X_t N^{-1/2} (N^{1/2} \Gamma N^{1/2})\mathbf{r}  \\
    & \\
     & \hspace{-1.75in} = X_t \Gamma X_t'(X_t\mathbf{p}) = X_t N^{-1/2} \lambda \mathbf{r} = \lambda X_t\mathbf{p}
\end{array} 
\end{equation} 
We can quickly verify that the set $\{v_t\}$ is orthonormal:

$$||X_t\mathbf{p}||^2 = \mathbf{p}'X_t'X_t\mathbf{p} = \mathbf{r}'N^{-1/2}X_t'X_tN^{-1/2}\mathbf{r} = \mathbf{r}' N^{-1/2} N N^{-1/2} \mathbf{r} = \mathbf{r}'\mathbf{r} = 1, $$

and:

$$ \langle X_t\mathbf{p}_i, X_t\mathbf{p}_j\rangle = \mathbf{p}_i'X_t'X_t\mathbf{p}_j = \mathbf{r}_i'N^{-1/2}X_t'X_tN^{-1/2}\mathbf{r}_j = \mathbf{r}_i' N^{-1/2} N N^{-1/2} \mathbf{r}_j = \mathbf{r}_i'\mathbf{r}_j = 0 $$
