The consideration to come out of this is that $\mathbf{w}$ resembling an AR(1) process does not necessarily suggest that $\uu$ is an ARMA process of the same order. namely if $\frac{\theta}{\phi} = \frac{\sigma_a}{\sigma_\eta^2}$. 

Proof:

Let us look at a few different cases and their respective implications on model selection.

Case 1: $\hat{\phi}$ and $\hat{\theta}_b$ are significant, as is $\hat{\theta}$ once it's calculated. In this case the model remains as is.

Case 2: $\hat{\phi}$ and $\hat{\theta}_b$ are significant, but $\hat{\theta}$ is not. To inform how inference informs model selection in this case, let's explore how the inclusion of an MA term interacts with the estimation of $\phi$ and $\sigma_\eta^2$ in the event that the true MA term $\theta = 0$.

Let's look at how Equation \ref{eq:H} changes under these circumstances:

\begin{equation}
    \label{eq:w-y-a_notheta}
    (1 - \phi B)^{-1}(1 + \theta_bB)b_t = (1-\phi B)^{-1}\eta_t + a_t 
\end{equation}
\begin{equation}
    \label{eq:w-y-a_notheta2}
    (1 + \theta_bB)b_t = \eta_t + (1 - \phi B)a_t 
\end{equation}
\begin{equation}
    \label{eq:H_notheta1}
    (1 + \theta_b^2)\sigma_b^2 = \sigma_\eta^2 + (1 + \phi^2)\sigma_a^2 
\end{equation}
\begin{equation}
    \label{eq:H_notheta1}
    \theta_b\sigma_b^2 = -\phi\sigma_a^2 
\end{equation}

Note that the second equation now only includes variables that are estimable from $\mathbf{w}$. Because we only now have one variable to estimate, $\sigma_\eta^2$, we only need the first equation. We can then give the following expression:

\begin{equation}
    \label{var_eta_hat_no_theta}
    \hat{\sigma}_\eta^2 = (1 + \hat{\theta}_b^2)\hat{\sigma}_b^2 - (1 + \hat{\phi}^2)\hat{\sigma}_a^2 
\end{equation}
